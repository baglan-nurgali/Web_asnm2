Summary of Work Process

1.HTML Structure:Developed a semantic markup layout containing separate sections for navigation, cards, grid components, image galleries, and the portfolio.
2.Styling & Flexbox:Configured global styles and utilized Flexbox for alignment in the navbar, card rows, and inner card contents to maintain flexibility and equal heights.
3.CSS Grid Implementation:Applied grid templates and areas for the page layout, image gallery, and portfolio grid structure to ensure proper positioning and gaps.
4.Interactivity & Effects:Added CSS transitions, hover transforms (lift and shadow effects), and responsive button states.
5.Testing & Validation:Verified that all links work properly, images load correctly, and layouts adapt cleanly across elements.
